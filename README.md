# Sistema de correspondencia

Aplicación web para registrar correspondencia entrante (P04).

## Ejecutar

Requisito: Node.js 20 o superior. No necesita instalar dependencias.

```sh
npm start
```

Abrir http://localhost:3000. Para detener, Ctrl+C.

## Pruebas

```sh
npm test
```

Los registros se guardan en `data/correspondencia.json`, fuera del control de versiones. Mantener una copia de esta carpeta para respaldarlos. Esta entrega es una aplicación local de demostración; el servidor escucha únicamente en el equipo local.
